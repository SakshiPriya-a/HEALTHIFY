# Healthify – AI Healthcare Chatbot

Healthify is an AI-powered healthcare chatbot designed to make medical advice more accessible and efficient. Built using Scikit-Learn, it enables patients to input their symptoms, interact with the chatbot for further questions, and receive appropriate medical advice, including the diagnosed problem name and a personalized diet plan.


# 🚀 Key Features

🏥 Symptom Analysis – Users input their symptoms, and the chatbot collects additional details.

🤖 AI-Powered Diagnosis – Trained with Scikit-Learn models to recognize symptoms and suggest possible conditions.

🥗 Diet Recommendations – Provides tailored diet plans based on health conditions.

💡 Medical Advice – Suggests care instructions and steps patients can take at home.

⚡ Quick & Accessible – Patients can access medical guidance without visiting a healthcare facility.

👩‍⚕️ Support for Professionals – Helps reduce workload for doctors by handling common and basic cases, allowing them to focus on complex medical issues.


# 📌 Problem It Solves

Limited access to immediate healthcare advice.

Long waiting times at physical facilities.

Overburdened healthcare professionals.

Healthify bridges the gap between patients and healthcare providers by offering reliable, AI-driven support at scale.


# 🛠️ Tech Stack

Python
